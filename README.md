# Sistema de Gestão de Vendas Desktop

## Status do Projeto
> :construction: Em desenvolvimento (Etapa 5 - Projeto Integrador)

## Objetivo do Software
O software foi desenvolvido com a finalidade de informatizar e agilizar o fluxo operacional de vendas e gerenciamento de estoque para estabelecimentos comerciais. O sistema permite o controle de produtos em tempo real, baixa automática de estoque após cada venda e emissão de resumos detalhados em ambiente desktop.

## Tecnologias Aplicadas
- **Linguagem de Programação:** Java (JDK 17)
- **Interface Gráfica:** Java Swing / AWT
- **Sistema Gerenciador de Banco de Dados (SGBD):** MySQL 8.0
- **Conectividade:** JDBC (Java Database Connectivity)
- **IDE de Desenvolvimento:** Apache NetBeans
- **Controle de Versão:** Git e GitHub

## Funcionalidades do Sistema (Requisitos)
- **RF01 - Autenticação de Usuários:** Tela de login e senha com validação de credenciais.
- **RF02 - Gerenciamento de Estoque:** Cadastro, listagem e exclusão de produtos com persistência em banco de dados.
- **RF03 - Registro de Vendas:** Seleção de cliente e adição de itens com verificação em tempo real de saldo de estoque.
- **RF04 - Cálculo de Totais:** Totalizador automático dos itens e cálculo de subtotais por quantidade.
- **RF05 - Baixa no Estoque:** Atualização imediata da quantidade disponível na base MySQL após a finalização da compra.
